# Ride Sharing Analysis - Delhi NCR 🚗

A data analytics project analyzing ride-sharing trip data from Delhi NCR (National Capital Region). The project focuses on cleaning raw trip data using Python and building an interactive business dashboard using Power BI.

## 📊 Dashboard Preview
![Dashboard Preview](Dashboard_Preview.png)

## 📁 Project Overview
This project aims to uncover revenue trends, vehicle performance, and booking patterns within the ride-sharing market. The data was sourced from publicly available trip records and cleaned extensively before visualization.

## 🛠️ Tech Stack & Tools
- **Python (Pandas):** Used for data cleaning, handling missing values, and generating the "Total Fare" column.
- **Power BI Desktop:** Used to create interactive visuals including revenue cards, line charts, bar charts, and pie charts.

## 📂 Files Included
- `clean_data_fixed.py` – The Python script used to clean the raw dataset.
- `cleaned_rides.csv` – The final cleaned dataset ready for analysis.
- `Ride_Sharing_Dashboard.pbix` – The complete Power BI dashboard file.
- `Dashboard_Preview.png` – A screenshot of the final dashboard for quick viewing.

## 📈 Key Insights
- **Total Revenue:** 52M+
- **Top Vehicle:** Auto and Go Mini generated the highest revenue.
- **Booking Status:** Over 66% of bookings were successfully completed.
- **Revenue Trend:** Daily trends show consistent ride activity with notable fluctuations.

## 🚀 How to Use
1. Download the `.pbix` file and open it in **Power BI Desktop**.
2. The data is already pre-cleaned, so the dashboard is ready to interact with immediately.
3. You can explore the Python logic in `clean_data_fixed.py` using any Python IDE.
